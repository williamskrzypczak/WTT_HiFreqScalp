👀 How to Read Signals

  1. Pivot Signals: Green triangle up (Long) and White triangle down (Short) mark key EMA crossovers.
  2. SMP Dots: Large yellow dots (S/W) signal strong momentum peaks; small purple dots indicate weaker setups.
  3. Profit Targets: 🎯 emoji appears when price reaches the profit target level
  4. Stop Losses: 💀 emoji appears when price hits the stop loss level
  5. Table Analysis: The on-chart table shows RSI, ADX, volume, trend direction, and market structure. 📊
  6. Trend Duration: Table displays trend duration predictions and historical pattern analysis. ⏱️

🔔 Alert Setup

  1. Click the ⏰ Alarm Clock icon on TradingView.
  2. Select WTT HiFreqScalp as the indicator.
  3. Configure settings:
    • Fixed Pip Distance: Set to 5.0 pips by default (1.0-50.0 range) for consistent targets
    • Use Fixed Distance: Toggle between fixed pip distance and dynamic calculation
    • Signal Spam Filter: Adjust bars between signals (1-20) - lower for more frequent signals, higher for fewer
    • Volume Filter: Disabled by default - enable for stricter volume confirmation
    • Candle Pattern Filter: Disabled by default - enable for pattern confirmation
    • Market Structure Filter: Disabled by default - enable for structure alignment
    • Enable Alerts: Toggle all alerts on/off
  4. Choose alerts:
    • 🟢 Syzygy Pivot Long/Short – EMA cross signals
    • 💪 Syzygy Momentum Peak – SMP signals with success probability
    • 🎯 Price Projection Target Reached – Profit target hit alerts
    • 💀 Stop Loss Hit – Stop loss triggered alerts
  5. Set alert actions (popup, email, webhook, etc.). 📱
